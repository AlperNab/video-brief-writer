# video-brief-writer

> **Topic or URL → complete YouTube/TikTok video production brief.** Hook formulas, script outline, thumbnail concepts, title variants with CTR prediction, SEO tags, retention tactics, upload strategy.

[![PyPI](https://img.shields.io/pypi/v/video-brief-writer?style=flat)](https://pypi.org/project/video-brief-writer/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## Quickstart

```bash
pip install video-brief-writer

python -m video_brief_writer "Why most people fail at learning new skills"
python -m video_brief_writer "investing for beginners" --platform YouTube
python -m video_brief_writer "productivity tips" --url https://example.com/article
```

## What's in the brief

- **Hook** — primary scroll-stopper + 3 alternatives with formula labels
- **Titles** — 5 variants ranked by predicted CTR with psychological trigger explained
- **Thumbnail** — concept, text overlay (max 5 words), emotion, face expression
- **Script outline** — timestamped sections with talking points + retention tactic per section
- **SEO** — primary keyword, 20 tags, optimized description first line
- **Engagement** — comment bait question, like trigger moment, subscribe hook
- **Upload** — best day + time window, first-hour action checklist
- **Repurposing** — which clip becomes a Short, Twitter thread, LinkedIn post
